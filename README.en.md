# AI-News · AI Meow Lab

A self-hosted AI news reader based on AIHOT, with its own branding. See the [Chinese project guide](README.md), [installation](docs/deploy.md), [configuration](docs/配置参考.md), and [dated acceptance status](docs/验收与现状.md).

The current installation runs an RSS-only collector. Full AI processing is disabled. Source material remains explicitly unverified; collecting a feed does not verify facts or create a selected item or edition. Public reads never start model calls.

Code retains the upstream [MIT license](LICENSE), [notices](NOTICE), and history. Source publishers retain rights to their material.
