# 本地开发

[返回 README](../README.md) · [配置](配置参考.md)

需要Node.js ≥24.22.1、npm及PostgreSQL17。Node24原生运行TS；后端不另编译，前端SSR需要构建。下面仅在新建的开发环境执行，不能在生产重复迁移、seed或测试。

```bash
npm ci --no-audit --no-fund
```

准备名为 `ainews_dev` 的隔离数据库（普通业务角色拥有该库），监听例如 `127.0.0.1:43184`。可由本机PostgreSQL管理员建库，或另外配置开发容器；不要让开发URL连接生产。新建仓库外 `../ai-news-dev/backend.env`，权限0600，参考 [backend模板](../deploy/portable/backend.env.example)，至少改为：

```dotenv
NODE_ENV=development
AIHOT_ENVIRONMENT=development
DATABASE_URL=postgres://<开发角色>:<URL编码密码>@127.0.0.1:43184/ainews_dev
SITE_URL=http://localhost:43181
API_PORT=43182
API_HOST=127.0.0.1
AIHOT_DATA_DIR=/absolute/path/ai-news-dev/data
COLLECT_ENABLED=false
MODEL_CALLS_ENABLED=false
```

模板内密码和签名密钥自行安全填写；占位符不能直接运行。以下从仓库根执行：

```bash
node --env-file=../ai-news-dev/backend.env scripts/migrate.ts
node --env-file=../ai-news-dev/backend.env scripts/seed.ts
node --env-file=../ai-news-dev/backend.env apps/api/src/main.ts
```

另开终端启动开发web，显式传入API地址；无需把backend.env加载到web：

```bash
SITE_URL=http://localhost:43181 API_BASE_URL=http://127.0.0.1:43182 npm run dev:web
```

打开 `http://localhost:43181`；管理员入口 `/admin`，密码是刚配置的 `ADMIN_PASSWORD`。seed只新增缺失信源，不覆盖已有后台配置，也不会生成新闻。独立RSS采集要另按[collector说明](部署与维护.md#独立-collector)启动，不能把空库启动成功当完整内容链路验收。

## 检查

```bash
npm run typecheck
npm run build
node --test apps/web/tests/*.test.ts
npm run test:standalone
```

数据库测试使用独立且以 `_test` 或 `_ci` 结尾的数据库，测试会写入/清理数据。完整 `npm test` 的 `tests/databases.ts` 会创建并行测试库，账号须有CREATEDB；不要因此提升生产角色权限。先读测试准备逻辑再提供对应URL，不能对生产运行。homelab的 `verify:integration` / `verify:backend` 与 `deploy/ai-news/run.mjs` 是特定设备/证据目录/既有角色的受控脚本，不是新机器通用安装命令。

`npm run dev:api` / `dev:worker` 会读取仓库 `.env`，且API引擎默认端口3001；本指南选择显式env-file和43182以避免歧义。完整worker会消费积压，即便模型阀关闭也会处理非模型任务，调试页面时无需启动它。

修改 `site` 或 `industry` 时见[定制指南](customize.md)。升级依赖同步审查锁文件；根目录一次 `npm ci` 足够，不在各workspace分别安装。密钥、数据库、缓存、截图、日志、构建产物均不提交。

## CI

`.github/workflows/check.yml`保留可手动触发的隔离检查，端口及Docker步骤使用本项目模板。当前交付的项目执行限定homelab，因此push/PR不会自动启动远端runner。本轮未执行GitHub Actions，不能宣称该远端完整流水线已通过。只有维护者另行选择`workflow_dispatch`时才会在GitHub运行；CI中的一次性测试常量不是真实凭据。
