# 信源扩充与中心球体自转（2026-10-27）

按用户要求将启用信源从 26 个扩充到至少 100 个，并让关于页中心球体绕屏幕垂直轴自转。

## 信源筛选与复现

通过 anysearch 寻找官方博客、研究团队、开源项目与技术媒体，并参考 `xiangyugongzuoliu/awesome-rss-feeds-list` 的 OPML 发现候选。目录只用于发现地址，最终以 Homelab 上现有 `fetchRss` 的真实匿名 HTTP 响应为准；检查有效标题、HTTP(S) 文章链接、发布日期及近期更新。未调用模型或付费抓取服务进行验证。

共检查 291 个候选地址（含地址变体及 20 个 GitHub 发布订阅）。最终新增 76 个独立订阅地址；排除重复返回同一订阅、非官方镜像、无法访问、占位文章、无效链接、只有更新时间没有发布日期及日期异常的来源。InfoQ 中文订阅实测把北京时间标为 GMT，部分条目超前约八小时，本次不加入，也不把采集时间当成发布时间。GitHub Atom 发布订阅未提供可供当前采集器使用的发布日期，本次不加入。

原有 26 个配置保留；102 个可复建配置统一存于 `industry/sources.json`，seed 只插入缺失项，不覆盖管理员修改。新增 28 个官方/机构 T1；新增 21 个中文、1 个中英双语、54 个英文信源。英文官方与研究机构占比较高，中文补充媒体、研究博客和技术社区；不把这个分布称为中英文各半。综合技术来源仍需经过现有 AI 预筛选和评分，收录不等于进入精选。

新增源的逐源检查时间、地址、有效条目数和样本保存在 [验证记录](sources-validation-20261027.json)。所有新源默认摘要和原文链接，`site_fulltext=false`、`syndicate_fulltext=false`，未变更已有来源许可。

首次导入每源最多 3 条、最近 6 个月内的存量，仍按原文日期归档、不冒充今日新闻；后续由原生 worker 调度。新源通常每 180 分钟检查，arXiv AI 每 360 分钟检查，之后可由现有自适应规则调整。采集与模型预算、评分门槛、推送开关保持既有配置，不创建第二个 worker。

## 中心球体

`SignalRiver.tsx` 分开处理倾斜星环与球面坐标。球面纹理用经度、纬度投影，约每 16 秒绕垂直轴旋转一周；云带与经线纹理移入、移出可见半球，轮廓及照明保持固定。继续响应减少动态效果、页面不可见与组件卸载；未引入动画框架或新依赖。
