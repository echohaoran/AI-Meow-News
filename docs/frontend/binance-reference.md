# Binance Reference 前端视觉改版

## 设计依据

2026-10-27 按用户指定，通过 Open Design MCP 的 `list_projects` / `get_file` 读取 **Binance Reference / 视觉参考设计体系 Design System**，项目 `brand-binance-reference-e2da6b`，体系 `user:binance-reference`。依据设计说明、design-contract、implementation-handoff 与 semantic.light / semantic.dark 令牌实施。原始导出保存在 `site/brand/binance-reference/`，不修改参考项目。

本站保留 AI-News 名称、猫形标识、真实内容和厂商 Logo；借用视觉规范，不加入交易、余额、金融业务或 Binance 品牌。未新增依赖、数据库迁移、模型任务或外部字体。

## 实施约定

- 白色 / 炭灰画布，黄色 `#FCD535` 主操作、深色按钮文字；浅色正文链接使用可读金色 `#795C00`，不把亮黄色用于白底小字。
- `apps/web/app/app.css` 映射既有语义角色到参考令牌。使用本机 SF Pro / PingFang 字栈、4/8px 间距节奏、8px 控件和 16px 卡片圆角，减少阴影与玻璃效果。
- 桌面侧栏 240px，通常内容宽 1120px；文章保留 1320px 容器、左侧段落目录和原有右栏。保留既有 961px 导航切换断点，目录在扣除页头的可用视口内居中，避免长目录覆盖页头。
- 桌面页头包含真实面包屑、RSS 和复用的全站搜索框；首页和全部动态沿用各自已有搜索框，避免重复 ID 和快捷键。手机继续使用原有搜索层与筛选弹层。
- 首页、主题索引、主题详情、排行榜、阅读页及关于页共用统一组件。主题分组数量来自 API 数据；排行榜与关于页数据保持真实，关于页动画只改配色。猫形 SVG 及其 PNG/ICO 派生素材同步更新。
- 页面仍只经 HTTP 读取公开 API，访问和主题切换不触发模型。中文正文、原文按钮、推荐信息、收藏、段落目录和厂商标识继续使用原有业务流程。

## 验证

服务器 Node 24 环境通过类型检查、前端生产构建、6 项页面 SSR 回归及 9 项厂商标识/排行榜离线回归。沿用已有测试边界：未声称完整数据库或全浏览器测试组通过。

真实浏览器检查 1269×980 桌面和 375×812 手机：浅色/深色主题、主题索引、排行榜、关于页和阅读页均已观察。主要语义文字、操作、焦点及控件边界共每主题 22 对对比度检查通过；最小文字比率为浅色 4.77、深色 5.45。该检查覆盖指定令牌组合，不等于全站无障碍认证。

实测桌面搜索进入 `/all?q=OpenAI`；收藏切换并恢复原状态；排行榜图片分类与月度周期切换有效。雷峰网示例文章有 22 项目录，点击第三节后位置距视口顶约 88px，左右栏和顶部原文按钮保留。375px 下主题与排行榜无页面横向溢出，手机外观按钮可用高度 44px。
