# AI-News · AI喵实验室品牌资产

字标为 AI-News，中文品牌为 AI喵实验室；日报入口使用 AI喵日报。猫耳轮廓与信息节点由本项目用 SVG 几何绘制，不使用团队头像、上游 Logo、banner 或营销素材。

site/brand/Logo.tsx 提供可访问字标与小图形；logo.svg 是图标正本，PNG 图标与 ICO 从该文件生成。wordmark.svg / wordmark-dark.svg 供分享图使用。nameplates/ 使用本地系统文字排版，不依赖字体下载；中英文实际字形由运行系统决定。MIT 代码许可及 NOTICE 中的字体许可保持原样，字体许可不被当成本站标识。

界面采用黄色强调色与浅色、深色语义变量，具体依据见 [Binance Reference 改版](binance-reference.md)。导航、新闻列表、详情、搜索筛选、收藏、板块及报告沿用 React Router 和真实 API 数据；桌面侧栏包含联系和 Coffee 入口，手机底栏为精选、热点和我的。首页快捷入口的行为见[说明](首页快捷入口.md)。

Local VM原生浏览器已验证部分手机响应式页面和导航；实机、软键盘及完整浅深色等未验。详见[验收与现状](../验收与现状.md)，源码与构建不代替视觉验收。
