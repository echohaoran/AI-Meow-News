# 文章阅读

2026-10-27 最终要求覆盖同日早先的短导读、右侧目录及仅显示外文原文方案。

- `/items/:id` 与加载预览均不显示 AI 导读；基础摘要继续供列表、刊物等既有出口使用。
- 顶部“打开原文”直接访问来源。中文原文展示正文，外文展示当前修订的完整中文译文，保留代码、图片与链接；不展示未完成的中外文混合稿。
- 翻译未完成时显示中文等待说明，每 10 秒重新读取详情。没有确认正文的条目提示访问原文，不能伪造或补写缺失正文。`/items/:id/original` 的网页入口重定向到中文阅读页，原有 HTTP 原文接口仍可用。
- 从桌面 `lg` 断点显示三栏。左栏为返回、可点击目录和来源时间，整栏在视口内垂直居中并在内容过长时滚动；目录文字保持左对齐。右栏保留收藏、更多操作、推荐理由、评分、主题和标签。其他使用 ArticleLayout 的页面沿用原来的布局。
- 手机保留底部阅读工具与目录弹层。目录按实际显示正文生成；没有 h2–h4 时增加“正文”及代码示例锚点，点击跳转预留顶部空间。
- 翻译只在后端执行。每 5 分钟的原生任务覆盖所有公开全文文章，以及原有精选帖及引用；仍经过模型回执、预算、修订匹配和三次失败限制。完整正文不再按 60,000 字符截断，继续分块调用模型。
