## API 接入与精确缺项

依据 docs/backend/API契约.md 与 packages/contracts 的既有类型，前端继续通过 apiGet/loadOr404 读取 /api/site 系列接口：

| 页面 | 实际接口 |
|---|---|
| 首页精选与分页 | GET /api/site/timeline；category/channel/tag/cursor |
| 全部动态、搜索与筛选 | GET /api/site/pool；q/tab/page/category/channel/tag |
| 新闻详情与原文 | GET /api/site/items/:id、/original |
| 热点与事件 | GET /api/site/hot、/api/site/stories/:publicId |
| 日报/周报/月报 | GET /api/site/reports/:kind/latest-page、/:key |
| 主题、元信息、说明 | /api/site/topics、meta、stats、contact、changelog；其余原生能力保持既有读取路径 |

服务端 client 的真实环境变量为 **API_BASE_URL**，不是契约初稿写的 API_ORIGIN。部署必须提供 API_BASE_URL=http://127.0.0.1:43182（容器部署时用对应内部服务地址）；前端浏览器只访问同源路径。前端没有读取任何 .secrets 文件、数据库或模型凭据，没有发起采集或模型调用。

真实 API 检查尚未取得健康响应，故新闻列表字段的运行时匹配、真实新闻详情与原文、搜索筛选返回、热点事件和日报均未验收。契约和编译通过只证明静态对齐。
