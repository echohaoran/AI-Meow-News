# 主题页厂商标识

2026-10-27：公司与模型分组的 15 个主题显示实际厂商 Logo，沿用已有 BrandMark 组件，电脑卡片、手机列表与主题详情页共用同一份品牌数据。技术方向与内容类型分组保持原状。

## 实现

- `modules/company-marks` 使用既有 `ServerModule.topics.marks` 接口提供按主题 slug 对应的 Brand，发布读取层仍统一生成主题响应。
- 本站通过 `site/modules/index.ts` 与 `site/modules/server.ts` 注册模块。模块声明 `/api/site/topic-marks/:slug`，网页沿用现有 API 转发机制。
- 静态 SVG 通过现有 `sendFile` 发送，使用 ETag 与一天缓存，只允许显式配置的厂商名称；未知名称和原型属性名返回 404。
- 12 个厂商复用排行榜已有素材：OpenAI、Anthropic、Google、DeepSeek、千问、Kimi/月之暗面、MiniMax、智谱、xAI、Meta、Microsoft、NVIDIA。
- Hugging Face、Cursor、OpenRouter 补充在 `site/brand/companies/`，来自 LobeHub Icons `@lobehub/icons-static-svg` 1.101.0，附 MIT 许可。没有增加 npm 依赖。所有图标由本站发送，读者页面不向第三方请求 Logo。
