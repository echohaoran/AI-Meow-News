# 首页快捷入口

首页介绍区提供三个入口：

- **RSS 一键订阅**：在新标签页打开现有 `/feed.xml` 精选摘要订阅。是否直接唤起阅读器取决于浏览器与用户的阅读器配置，网页不会自动替用户创建订阅。
- **Agent 提示词快速复制**：复用现有剪贴板工具，复制带当前访问地址 `/api/v1/agent` 的提示词。Agent 先读取接入说明，再查询过去 24 小时的重要精选，附中文摘要、发布时间、站内阅读与原文链接；无结果或访问失败时如实说明。
- **MCP 地址快速复制**：复制当前访问地址下的 `/api/mcp`，可粘贴到支持远程 MCP 的客户端；连接设置及命令示例可在“Agent 接入”页面查看。

复制操作显示成功或失败反馈，2.5 秒后恢复按钮文字。MCP URL 需添加到兼容客户端的远程连接器配置中，直接粘贴进聊天输入框不会建立连接。此入口已上线；具体发布记录见[交接记录](../handoff.md)。
