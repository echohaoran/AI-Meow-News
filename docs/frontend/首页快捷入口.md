# 首页快捷入口

首页介绍区提供两个入口：

- **RSS 一键订阅**：在新标签页打开现有 `/feed.xml` 精选摘要订阅。是否直接唤起阅读器取决于浏览器与用户的阅读器配置，网页不会自动替用户创建订阅。
- **Agent 提示词快速复制**：复用现有剪贴板工具，复制带当前访问地址 `/api/v1/agent` 的提示词。Agent 先读取接入说明，再查询过去 24 小时的重要精选，附中文摘要、发布时间、站内阅读与原文链接；无结果或访问失败时如实说明。

复制操作显示成功或失败反馈，2.5 秒后恢复按钮文字。手机与桌面入口纵向排列，平板两列排列。本次仅修改本地首页和样式，未部署服务器。
