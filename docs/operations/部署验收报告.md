## 原始失败与具体纠正

1. 自编预检使用Git默认转义输出，把中文docs路径误判为额外代码，退出1；改为 `git ls-files -z` 后校验通过。失败发生于DB变更和构建之前，原始记录为 `preflight-path-quoting-failure.json` 及ops同名log。
2. Docker Hub直连发生 `read: connection reset by peer`，首次构建exit1；改用本项目已经使用的镜像入口拉取同版本镜像，并只给构建传现有代理，构建exit0。`docker-build.log`、`docker-build-mirror.log`均保留；未改Docker全局配置或应用源码，未重复相同失败命令。
3. 自编页面验收误要求登录页含“AI喵”，实际正确标题为“登录 · AI-News 后台”；修正该页断言，保留 `verification-login-brand-assertion.*`，当时尚未执行认证写入或重启。
4. DB重启后SQL/API已经恢复，Docker周期健康状态仍短暂starting，基线检查提前退出1；实际认证、写入恢复、注销及持久化检查已经全部通过。保留 `verification-health-starting-assertion.*`，增加有界健康等待，随后只恢复只读收尾，exit0；没有重复登录写入或再次重启。完整终态见 `production-verification.json`、`verification-resume-status.json`。
