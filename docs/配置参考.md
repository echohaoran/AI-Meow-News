# 配置参考

[返回 README](../README.md) · [部署](deploy.md) · [维护](部署与维护.md)

变量依据 `packages/backend/src/config.ts`、`site/models.ts`、web server 和两份 Compose。环境变量覆盖可选凭据组文件；`AIHOT_CREDENTIALS_DIR` 下可按 `models.env` / `collectors.env` / `integrations.env` / `auth.env` 分组，文件名可由站点配置指定。新部署使用 [backend.env.example](../deploy/portable/backend.env.example)，不是生产凭据副本。

| 变量 | 引擎默认 / 模板值 | 用途 | 秘密 |
|---|---|---|---|
| `DATABASE_URL` | 引擎本机5432/aihot；模板 `db:43183/ainews` | 后端数据库，必须显式指定正确库 | 是，可能含密码 |
| `SITE_URL` | `SITE.defaultUrl`；模板 `http://localhost:43180` | 生成链接、RSS、分享与来源校验 | 否 |
| `API_PORT` / `API_HOST` | 3001 / 127.0.0.1；Compose覆盖43182 / 0.0.0.0 | API监听 | 否 |
| `API_BASE_URL` | http://127.0.0.1:43182；容器必须覆盖 | SSR和web代理访问后端；容器 `http://api:43182` | 否 |
| `WEB_PORT` / `WEB_HOST` | 43181 / 127.0.0.1；Compose host为0.0.0.0 | web监听 | 否 |
| `NODE_ENV` / `AIHOT_ENVIRONMENT` | 非production / 随NODE_ENV | 生产校验、告警环境 | 否 |
| `SESSION_SECRET` / `IMG_PROXY_SIGN_SECRET` | 无 | 会话/图片签名；各自独立高熵随机值 | 是 |
| `ADMIN_PASSWORD` | 无 | 管理员密码至少12字符，或配置飞书管理员登录 | 是 |
| `AIHOT_DATA_DIR` | 仓库 `.data`；容器 `/data` | 附件、缓存、本地备份等持久数据 | 数据敏感 |
| `DATABASE_POOL_MAX` | 10；homelab为4 | 单进程连接池上限；多角色须合计容量 | 否 |
| `LLM_BASE_URL` / `LLM_MODEL` | 均无有效默认值；新模板留空 | OpenAI兼容服务地址和精确模型名 | 地址可能敏感 |
| `LLM_API_KEY` | 无可用密钥默认值 | 模型鉴权；只进入后端 | 是 |
| `LLM_EXTRA_JSON` / `LLM_JSON_MODE` / `LLM_VISION` / `LLM_REASONING_TOKENS` | 未设 / true / false / 0 | 服务特有请求、JSON、图像及推理额度 | 否 |
| `COLLECT_ENABLED` | 未设为false；示例false | 必须精确 `true` 才抓来源 | 否 |
| `MODEL_CALLS_ENABLED` | false | 必须精确 `true` 才调模型；不是启动worker的替代品 | 否 |
| `FEISHU_CONTENT_PUSH_ENABLED` / `FEISHU_INTERNAL_ENABLED` / `INDEXNOW_SUBMIT_ENABLED` | false | 各类外推开关，默认关闭 | 否 |
| `EGRESS_PROXY_URL` | 无 | 抓取/图片出站代理；模型接口不走该代理 | 可能含认证 |
| `PRIVATE_FEED_HOSTS` | 空列表 | 只精确放行自建内网订阅主机，不放行正文/重定向 | 否 |
| `TRUST_PROXY` | false；Caddy后的web为true | 仅在可信代理后信任转发访客地址 | 否 |
| `INGEST_TOKEN` / `INGEST_RATE_LIMIT` | token无；引擎不限，homelab10 | 外部写入token至少16字符；按客户端每分钟限流 | token是 |
| `AIHOT_RELEASE` | 可不设 | health与后台显示的版本标识 | 否 |

`true` 区分大小写，`1`、`yes`、`TRUE` 不打开安全阀。生产拒绝 `DEV_AUTH_*` 和 `ALLOW_PRIVATE_NETWORK_FETCH=true`，不要把开发免登录带入生产。管理员密码从运行环境配置，seed不创建默认管理员密码。Cookie为HttpOnly；HTTP入口不具备Secure/HTTPS保证。

默认模型由 `LLM_*` 提供；各能力可通过 `PREFILTER_MODEL`、`SCORE_MODEL`、`UNDERSTAND_MODEL`、`SUMMARIZE_MODEL`、`WORDING_MODEL`、`STRUCTURE_MODEL`、`GROUP_MODEL`、`GROUP_REVIEW_MODEL`、`DIGEST_MODEL`、`REPORT_MODEL`、`TRANSLATE_MODEL` 或后台设置选路，由 `site/models.ts` 定义具名预设。容器入口只在缺少LLM值时映射既有 `OPENAI_BASE_URL` / `OPENAI_API_KEY` / `OPENAI_MODEL`；直接运行TS入口须自行提供LLM变量。不要凭模型名推断供应商已提供它。

向量、Jina、SocialData、微信公众号、飞书、IndexNow、对象存储备份等可选项见[环境示例](../.env.example)。填写某些凭据可能启用相应付费路径，启完整worker前逐项确认路由与预算。预算保存在数据库中，不是美元金额；开关不代表费用上限。新模板默认关闭模型调用；生产是否成功分析新资料还取决于模型服务和任务状态，参见[运行快照](验收与现状.md)。

## Compose层变量

可移植模板的 `compose.env` 只用于Compose插值，不整份传给web：

| 变量 | 模板值 / 要求 |
|---|---|
| `AI_NEWS_IMAGE` | 自建已审查镜像tag，必填 |
| `AIHOT_RELEASE` | 自建版本或提交标识，必填 |
| `AI_NEWS_BACKEND_ENV` | 仓库外backend.env绝对路径，必填 |
| `AI_NEWS_DATA_DIR` | 仓库外持久目录绝对路径，UID1000可写，必填 |
| `POSTGRES_PASSWORD` | 与backend DATABASE_URL密码一致；仅新模板DB使用，秘密 |
| `SITE_URL` / `INGRESS_BIND` | localhost:43180 / 127.0.0.1，按入口修改 |
| `AI_NEWS_COLLECTOR_IMAGE` / `AI_NEWS_COLLECTOR_RELEASE` | 可省略，沿用共同镜像/版本 |

既有homelab根Compose通过固定env_file读取父目录 `.secrets/production.env` 和 `backend-production.env`，并依赖外部 `ainews-db` 网络；这是既有环境专用入口。其生产出站代理覆盖和release.env也在仓库外，不是新clone前提。
