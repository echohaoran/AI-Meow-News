# 信源配图规则

`site/site.ts` 中的 `HIDDEN_ARTICLE_IMAGE_SOURCES` 按信源 ID 控制不展示文章图片。目前包含钛媒体（`rss-tmtpost`），因为该信源的配图主要是推广内容。

公开读取时隐藏该信源的列表缩略图、正文图片、视频海报和 RSS 全文图片；热点和报告封面从其他允许展示图片的来源中选择。信源图标、文章文字、视频和原文链接不受影响。规则同时适用于已收录和新收录内容，不改动原始采集数据。

2026-10-28：列表、正文、导出和热点封面相关的 36 项隔离测试通过；公开页面确认目标文章不带图片，其他信源图片仍可显示。生产 API 镜像为 `ainews-app:hide-tmt-2d1f4b43000f`，发布前的数据库和数据备份及恢复校验记录位于服务器 `/root/netops-backups/ainews-source-hide-20261028T000017Z/`。
