# 模型故障切换

站点默认模型由部署环境指定。此站以 Agnes `agnes-3.0-flash` 为主，使用独立的 DeepSeek `deepseek-flash` 作为备用；地址和密钥只放在服务器私有配置中。

备用路由覆盖预筛、评分、结构提取、内容理解、摘要、用词、事件归组与复核、事件综述、报告和中文阅读翻译。图片理解仅在备用模型也支持图片时自动切换，避免把图片发给纯文本模型。显式指定评分模型的评测不切换；评分的两次调用使用不同模型时，记录会标明两者。

主服务出现临时网络故障、暂时不可用或结果未知时，既有回执机制会交给备用服务；账号拒绝、预算耗尽、输入错误或不可用的模型输出不会自动绕过。超时后主请求可能已产生费用，备用请求也可能收费；每次请求仍按服务分别记录回执和预算。主服务的熔断和恢复探测由现有机制处理。

2026-10-28 在隔离数据库中用本地假服务运行了故障切换、文章分析及中文阅读测试，共 22 项通过；另用 DeepSeek 处理一条合成新闻样例，验证了预筛、两次评分、结构提取及内容理解的真实接口和回执。这个小样本证明链路可用，不能证明两家模型的评分已校准一致。
