# 模型故障切换

站点默认模型由部署环境指定。此站按 `gpt-6-luna`、`xiaomi-mimo/mimo-v2.6-flash`、`deepseek/deepseek-flash` 的顺序使用同一个 OpenAI 兼容网关；地址和密钥只放在服务器私有配置中。三个模型共用网关，网关本身故障时无法提供跨网关容灾。

备用路由覆盖预筛、评分、结构提取、内容理解、摘要、用词、事件归组与复核、事件综述、报告和中文阅读翻译。图片理解仅在备用模型也支持图片时自动切换，避免把图片发给纯文本模型。显式指定评分模型的评测不切换；评分的两次调用使用不同模型时，记录会标明两者。

主模型出现临时网络故障、暂时不可用或结果未知时，既有回执机制按顺序尝试后续模型；账号拒绝、预算耗尽、输入错误或不可用的模型输出不会自动绕过。超时后前面的请求可能已产生费用，后续请求也可能收费；每次请求仍按服务分别记录回执和预算。主模型的熔断和恢复探测由现有机制处理。

2026-10-28 在隔离数据库中验证三级路由、回执恢复、文章分析与中文阅读；另用三个模型各处理一条合成新闻样例，验证预筛、两次评分、结构提取及内容理解。网关中的 DeepSeek 在关闭思考参数时仍消耗推理额度，因此为其预留额外输出额度。这个小样本证明链路可用，不能证明各模型的评分已校准一致。
