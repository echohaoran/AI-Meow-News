
## 独立采集进程

collector 与完整 worker 是两个不同的角色。当前只恢复18个RSS来源的持续采集；collector只消费sources.fetch并按原生cron.sources.schedule每分钟安排到期来源（Asia/Shanghai），并发2。沿用原收录、身份去重、发布时间、首次导入每源最多30条及48小时归档规则。它仍按原规则创建后续处理任务，但不消费content.*、events.*、通知、发布或模块队列；不运行content.sweep、翻译、热点与日报编排。因此来源动态会更新，新的AI分析和自动成刊仍未启用。

collector强制COLLECT_ENABLED=true、MODEL_CALLS_ENABLED=false、外推/索引关闭；启动前拒绝启用的非RSS或detail抓取来源，运行时也拒绝这类fetch任务。以后要启用其他适配器，应先检查该来源的授权与付费预算，再调整独立入口；不要直接打开完整worker释放旧积压。

Compose使用collector profile，独立镜像/摘要来自父目录ops/production-release.env中的AI_NEWS_COLLECTOR_IMAGE与AI_NEWS_COLLECTOR_RELEASE，缺省沿用公共镜像/摘要。此角色无宿主端口，复用原DB网络/卷、restart unless-stopped和515秒正常退出宽限。部署由家庭运维持既有锁，仅up --no-deps collector，不改API/web已验镜像。停用时只stop collector；保留队列和原数据，不恢复旧dump覆盖回执。
