# 阅读分类

首页精选和全部动态的电脑筛选栏、手机筛选菜单按以下顺序显示：全部、模型、产品、行业、技术、商业、金融、其他。

| 分类 | 范围 |
|---|---|
| 模型 | 模型发布、版本、权重、能力、价格及榜单成绩 |
| 产品 | 应用、工具、API、平台和工程组件的发布更新 |
| 行业 | 政策监管、组织人才、诉讼、行业生态及安全事件 |
| 技术 | 论文研究、方法、实验、新基准、数据集、教程和工程实践 |
| 商业 | 商业化、商业模式、企业采购、客户落地与商业合作 |
| 金融 | AI 相关融资、并购、估值、上市、财务及资本市场动态 |
| 其他 | 已确认与 AI 相关但不属于上述主题的内容，以及未分类记录 |

一手来源仍是来源属性，不再作为这排分类入口。旧的 `channel=firstParty` 链接继续支持。

`industry/taxonomy.ts` 定义分类及分组。技术同时读取旧 `paper`、`tip` 类别，其他同时读取旧 `opinion` 和空类别；旧类别网址、公开接口身份和已存分类保留。分类模型只接收七个新分类的说明，评分标准和门槛不变。

本次不触发历史文章的模型重分类：旧行业记录中的商业、金融内容仍保持原分类，后续新分析按新边界分类。分类变化不会触发读者请求调用模型。

分类改动已随前端发布；历史验证与部署记录见[交接记录](handoff.md)。
