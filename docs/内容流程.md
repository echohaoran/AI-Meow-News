# 内容流程与展示规则

[返回 README](../README.md) · [信源](sources.md) · [精选](selection.md) · [归组](grouping.md)

1. **收录**：启用的来源到期后抓取列表，按原生身份键去重/记录修订，写文章与来源发布投影。列表的found数量不是新增数量；重复抓取不会重复计热。
2. **来源动态**：`/source-news`保留来源标题、摘要、URL和原始时间，明确“未核验/未精选”。这是可读原材料，不是事实认证或AI已完成状态。公开读取仍受可公开性规则约束。
3. **正文与分析**：完整处理角色补正文、预筛、双评分、理解/结构/摘要或翻译；每次付费请求经过回执和预算。正文unconfirmed只可按摘要处理，不能声称完整原文已核验。
4. **精选与归组**：达到门槛仍需确认新闻身份、增量信息与发布资格；代表报道避免重复新闻占据精选。不是所有eligible资料都selected。
5. **事件与报告**：原生规则计算事件、热度、日报编排与周期汇编；没有合格产物不造空刊或假热点。

## 来源、时间与历史

来源ID、平台域名、文章署名和实际开发机构是不同概念。Hugging Face承载的博客不代表Hugging Face开发了其中项目。原始来源披露与独立事实复测也应分开表述。

优先保留真实 `published_at`；`first_seen_at`是收录时间，不将其改作“今天发布”。无可信发布时间时先不进入正常公开列表/精选/报告/热点/推送，文章页等适用出口标注收录时间。不带时区的来源日期按来源配置解释，默认+08:00，不能按服务器时区猜测。

首次导入标 `backfill` / `first-import`，每源可配置 `initialBackfillLimit`（默认30，既有26个源配置8，新增76个源配置3）。回填不等于把所有内容归历史：原规则以真实日期和发现时点判断，超过48小时或缺日期的回填归历史；历史内容不靠改日期进入今天、热点或日报。后续抓取旧存档有时间截断，见[信源规则](sources.md)。

## 分数与刊物

`industry/selection.ts`目前T1/T1_5/T2平均门槛为60/65/76。每条独立评分两次，两次之和至少为门槛两倍；不能用一次高分替代双评分。未入选但均分达到50可走较完整理解写作，否则可走标题摘要翻译；最终仍以公开发布投影为准。门槛改动需真实标注样本评测。

热度看近48小时的独立参与者，同一参与者计一次，按24小时半衰期衰减，至少2个独立参与者且至少1个报道方。单源当前事件不自动上榜。精选历史文章可保留在精选归档，不因此变成近期热点。

热点榜前三张卡片的右上角与底部说明共用事件角标：“爆”表示最近6小时内参与讨论的独立参与者至少3位且占窗口参与者至少一半；“新”表示首报不足6小时；未达“爆”且可比热度较6小时前增长超过15%时显示“发酵中”。角标可同时显示“爆”和“新”，无符合条件的角标时留空，不用“暂不比较”等走势状态替代。

完整版次以Asia/Shanghai为准：日报08:00、周一周报10:00、每月1日月报10:30；完整worker的报告检查每半小时执行。日报按规则编排，周/月报从日报汇编，模型可参与周期总述/栏目导读；这些时间是计划，不是当前运行承诺。日报要求对应窗口的合格资料，回填/未评分/撤回材料不能为凑数混入；缺合格内容或前置日报不齐时保留未成刊边界。

## 两种运行角色

独立collector每分钟安排到期来源、最多2并发抓RSS，只支持已启用RSS且无detail抓取的来源。它会正常创建后续content任务，但不消费正文、分析、事件、报告或模块任务；因此来源数增长而分析/精选不变是当前设计状态。

完整worker注册广泛消费者，旧created任务可能立即被领取。`COLLECT_ENABLED=false`只限制采集，`MODEL_CALLS_ENABLED=false`只限制模型请求，不能等同“不处理队列”。当前 Homelab 部署已启用完整 worker；collector 仍不是完整处理角色。

## 更正与审计

人工编辑通过原生admin内容覆盖接口，带版本校验、理由和审计，保留raw analyses、模型回执及原日期。更正摘要不意味着重跑评分或选稿；关联事件综述需另行核对是否刷新。涉及相对百分比、百分点、评测范围、开发方或合作方披露时应回到原文，不能把模型摘要当事实证据。

有界运维工具 `content-once.ts` / `correct-content.ts`是生产修复专用，有限额、库名/模型/marker保护，不是通用快速开始，也不能换label盲重跑付费事务。

## 中文整理阅读

本站公开文章优先阅读后台生成的独立中文整理稿，中英文来源使用同一事实整理流程，保留原文入口、来源及章节目录。来源全文转载许可与原始素材保持独立，页面访问不调用模型；已有可用正文的历史条目已回填，新文章由原 worker 的 `reading.compose` 自动处理。正文未确认的条目等待真实材料，不凭标题补写全文。实现、修订匹配、回执与预算边界见 [中文整理稿](frontend/中文整理稿.md)。
